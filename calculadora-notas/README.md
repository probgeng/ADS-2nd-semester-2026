# Calculadora de Notas

Projeto desenvolvido para a disciplina de **Algoritmos e Estruturas de Dados** — 1º Semestre de 2026.

## Descrição

Aplicação web que recebe as notas de uma turma de alunos e exibe um relatório com estatísticas de aprovação, reprovação, zerados e pegos colando.

## Regras de negócio

| Entrada | Significado |
|--------|-------------|
| `-1`   | Aluno pego colando |
| `0`    | Aluno zerou |
| `1 a 10` | Nota normal |

- **Aprovado:** nota ≥ 7  
- **Reprovado:** nota entre 1 e 6  

## Funcionalidades

- Adição de notas via input ou tecla **Enter**
- Remoção de nota clicando na tag
- Cálculo de quantidade e porcentagem por categoria
- Cálculo de média geral e por categoria
- Botão de reinício

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## Como usar

Abra o arquivo `index.html` no navegador.
