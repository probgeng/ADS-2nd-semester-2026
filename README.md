# ADS — Exercícios JavaScript · 2º Semestre 2026

Repositório com exercícios práticos da disciplina de Algoritmos e Estruturas de Dados, convertidos de Java para JavaScript com interface web.

## Exercícios

### [calculadora-notas](./calculadora-notas)
Recebe as notas de uma turma e exibe relatório com aprovados, reprovados, zerados e pegos colando — com médias e percentuais por categoria.

### [sala-por-idade](./sala-por-idade)
Identifica a sala de um participante com base na faixa etária. Inclui os testes planejados no modelo ULIFE com execução automática no navegador.

## Tecnologias

- HTML5 · CSS3 · JavaScript Vanilla

## Como usar

Abra o `index.html` de cada exercício diretamente no navegador.
