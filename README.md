# ADS — Atividades · 2º Semestre 2026

Repositório com atividades práticas e exercícios do curso de Análise e Desenvolvimento de Sistemas.

## Exercícios JavaScript

Exercícios da disciplina de Algoritmos e Estruturas de Dados, convertidos de Java para JavaScript com interface web.

### [calculadora-notas](./calculadora-notas)
Recebe as notas de uma turma e exibe relatório com aprovados, reprovados, zerados e pegos colando — com médias e percentuais por categoria.

### [sala-por-idade](./sala-por-idade)
Identifica a sala de um participante com base na faixa etária. Inclui os testes planejados no modelo ULIFE com execução automática no navegador.

## Engenharia de Software

### [engenharia-de-software](./engenharia-de-software)
Respostas dos exercícios de Engenharia de Software — cobre fundamentos, modelos de processo, desenvolvimento ágil, engenharia de requisitos, padrões de projeto, qualidade/testes e práticas modernas de DevOps/CI-CD.

## Tecnologias

- HTML5 · CSS3 · JavaScript Vanilla
- Markdown

## Como usar

Abra o `index.html` de cada exercício JavaScript diretamente no navegador.
